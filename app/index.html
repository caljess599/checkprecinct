    SEARCH TIPS
    • When a street name includes a cardinal direction, use the single-letter abbreviation, e.g., W instead of West.
    • Street types must be abbreviated, e.g., ST, DR, LN, CT — but the autocomplete should find your address before you need to type them
    • You do not have to use your exact unit or apt number; the entire building will always be in the same precinct
    • Enter whole-numbered streets using the ordinal number, e.g., 5th rather than Fifth.
    • Enter fractional-numbered streets with the cardinal number followed by 1/2, e.g., 6 1/2

    How does this work?

    • This script makes API calls to public GIS data available at Open Data Charlottesville.
    • The source code is available on Github. (Last update: Sept. 2026)
